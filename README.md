# lead-to-srs

> 来源分类：**原创/AI打磨** ｜ 导出批次：published

将结构化客户/线索画像转化为标准需求文档(SRS)、系统架构、智能体方案或解决方案提案，含 BR/UR/FR/NFR 编号与需求追溯矩阵。适用于销售/售前对客户线索(C00x)做标准化产出。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/lead-to-srs        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/lead-to-srs   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。

- 本技能从本地 WorkBuddy 环境导出，**所有真实密钥已脱敏为占位符**，使用前请配置你自己的 API Key。
